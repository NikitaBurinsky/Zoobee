# ADR Workflow (Classic)

## Статусы

- `accepted` — решение действует.
- `superseded` — решение заменено более новым ADR.
- `rejected` — рассмотрено и отклонено.

## Правила

1. Каждый значимый архитектурный выбор фиксируется отдельным ADR.
2. ADR получает постоянный номер (`0001`, `0002`, ...).
3. Индекс ADR обязателен к обновлению при добавлении/изменении статуса.
4. При замене решения:
   - старый ADR получает статус `superseded`;
   - новый ADR содержит ссылку на заменяемый.
