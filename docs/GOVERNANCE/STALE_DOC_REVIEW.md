# Stale Documentation Review

Связанные записи: [Decision Log D-028](../DECISION_LOG.md), backlog `DOC-037`.

## Cadence

- Ежемесячно, в первую неделю месяца.
- Ответственный: владелец документации (см. [OWNERSHIP](../OWNERSHIP.md)).

## Что проверяем

- Страницы, не обновлявшиеся более 60 дней.
- Страницы, на которые ссылаются открытые high/critical risk items.
- Страницы, конфликтующие с текущим кодом.

## Результат review

- Для каждой устаревшей страницы: обновление или backlog item.
- Для критичных расхождений: immediate fix и/или ADR.
- Обновление `Decision Log` при изменении политики.
