# Ambiguity Protocol (Block-And-Ask)

Связанные записи: [Decision Log D-008](../DECISION_LOG.md), backlog `DOC-035`.

## Когда останавливаемся

- Неясно, зачем исторически принято решение.
- Код и документация противоречат друг другу.
- Есть несколько правдоподобных трактовок, влияющих на архитектуру/контракт.

## Что делаем

1. Фиксируем ambiguity в backlog с контекстом и риском.
2. Помечаем affected docs как `Needs Owner Clarification`.
3. Запрашиваем решение у владельца.
4. После ответа:
   - обновляем docs;
   - при необходимости оформляем ADR;
   - закрываем backlog item.

## Запрещено

- Молчаливо выбирать трактовку с архитектурным эффектом.
- Переопределять историческое решение без явной записи.
