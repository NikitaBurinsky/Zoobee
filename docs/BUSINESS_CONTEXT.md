# Бизнес-контекст MVP

Связанные записи: [ADR-0001](./ADR/0001-documentation-system.md), backlog `DOC-021`.

## Продуктовая цель

Zoobee — портал/агрегатор зоотоваров для поиска и сравнения предложений.

## Ключевые пользовательские потоки

- Покупатель ищет товары по фильтрам и выбирает предложение.
- Администратор управляет справочниками и seed-данными.
- Система парсинга подтягивает товары/офферы с внешних источников.

## Бounded contexts (фактические)

- `Catalog` (товары, атрибуты, фильтры, офферы).
- `Environment Data` (бренды, страны, компании, гео-зоны).
- `Identity/Admin` (роли, авторизация, DB admin контур).
- `Parsers` (scraping + transformation + failure handling).

## MVP-ограничения

- Допускаются legacy/WIP зоны при явной маркировке.
- Локализация временно не приоритетна для MVP (см. policy).
- Целевая архитектура роста: возможный вынос parser subsystem в отдельный сервис.
